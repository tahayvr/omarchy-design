The voice stays the same everywhere; the tone moves with the moment. A launch post can shout. An error message can't.

## Five words

| Omarchy is      | Like this                                             | Not like this                                                 |
| --------------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| **Confident**   | We picked the defaults so you don't have to.          | You may wish to consider configuring your preferred defaults. |
| **Plain**       | Press Super + Space to open anything.                 | Leverage the launcher to surface applications.                |
| **Fun**         | We can fix everything!                                | Omarchy delivers a best-in-class Linux experience.            |
| **Opinionated** | There's one bar. It's this one.                       | Choose from twelve bar layouts.                               |
| **Helpful**     | Wi-Fi is off. Turn it on from the menu to get online. | Network error.                                                |

## Tone by moment

| Moment                    | Turn it                                    | Example                                               |
| ------------------------- | ------------------------------------------ | ----------------------------------------------------- |
| Launches and the homepage | Up: big, warm, a bit cheeky                | Beautiful, fun & agentic Linux.                       |
| Docs and guides           | Middle: direct, second person, short steps | Open the launcher, type the app's name, press Enter.  |
| Errors and warnings       | Down: what happened, then what to do       | The update didn't finish. Run it again from the menu. |
| Destructive actions       | Flat: say exactly what goes                | This deletes the theme and its wallpapers.            |

## Writing rules

- Say what to press, not where to click. Omarchy is keyboard first.
- Name keys the way they're printed: Super, Ctrl, Shift, Enter.
- Sentence case everywhere, including buttons and headings.
- One exclamation mark, only when something's actually exciting. Never in errors.
- No jargon a new Linux user wouldn't know. If a term is needed, say what it does the first time.
