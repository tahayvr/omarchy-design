## The theme contract

A theme is a [`colors.toml`](../foundations/color/). When it's set, Omarchy fills a template for each app from its keys, so one file repaints the whole desktop. A theme can also ship its own file for any app to replace the generated one.

| Area                    | Apps themed from colors.toml                            |
| ----------------------- | ------------------------------------------------------- |
| Desktop shell           | The bar, lock screen, notifications, menus and controls |
| Window manager          | Hyprland's window borders and the screen-share picker   |
| Terminals               | Alacritty, Ghostty, Kitty, foot                         |
| Editors                 | Neovim, Helix, VS Code, Obsidian                        |
| System                  | btop, Chromium, the keyboard backlight                  |
| Command line and agents | gum, Claude, Pi, Hermes, T3 Code                        |

From the templates in Omarchy's `default/themed` folder.

## The parts

Every part of the desktop, painted from Omarchy's own `shell.toml` template. Pick any shipped theme — or paste your own `colors.toml` — and every preview repaints.
