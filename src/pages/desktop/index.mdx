## The theme contract

A theme is a set of values for the [color roles](../foundations/color/) plus the files that hand them to each app. These are the apps a theme covers today; the list is a draft to confirm.

| App                       | What it draws                                                |
| ------------------------- | ------------------------------------------------------------ |
| Terminal                  | Text, the cursor, selections and the sixteen terminal colors |
| Bar                       | Workspaces, the clock and status icons along the screen edge |
| Launcher                  | The menu that finds apps, commands and files                 |
| Notifications             | Messages in the corner, by urgency                           |
| Lock screen               | The password field over the wallpaper                        |
| On-screen display         | Volume and brightness while they change                      |
| Window borders            | The active window and the rest                               |
| Editor and system monitor | Terminal apps with their own themes                          |
